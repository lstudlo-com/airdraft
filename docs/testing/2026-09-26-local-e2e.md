# Local app E2E audit, 2026-09-26

This audit tests the macOS app with isolated data and explicitly excludes all
API-key-dependent features, credential operations and cloud-provider tests. No API
key was searched for, read, entered or pasted. Three agents covered native UI,
pipeline/audio, and settings/models, with independent cross-review of the fixes.

The [feature ledger](2026-09-26-feature-ledger.md) records 153 grouped acceptance
cases, including partial and unavailable variants.

## Repairs

- Recording rechecks speech/refinement/microphone/profile choices after permission
  waits. Denied permission and failed recorder startup open actionable Home recovery
  even when the HUD is hidden. Verbatim does not prewarm a refinement CLI.
- Text insertion requires a valid unchanged selection and checks it again before
  writing. Uncertain writes are not replayed. Context extraction handles UTF-16
  ranges and clips text without splitting Unicode characters.
- CLI warm sessions share bounded simultaneous input/output handling, cancellation,
  deadlines and failed-result rejection. Changing configuration replaces the stale
  warm session. Child pipe endpoints remain blocking.
- Vocabulary Undo preserves later aliases and spelling changes. Replacements do
  not repeatedly expand an already-correct preferred term.
- Local installation checks reject empty/missing/non-file assets. Download
  cancellation cleans temporary files and interrupts archive extraction.
- LM Studio rejects failed HTTP list/unload responses, targets exact instance IDs,
  remembers the endpoint used, retains failed cleanup for retry and protects active
  models against stale selection cleanup. Preparation uses the dictation's captured
  configuration and waits for an unload already sent to the server.
- Shortcut recording releases Carbon registration until completion. Switching
  between System Default and the same physical device preserves its input channel.
  Choosing HUD None immediately hides an existing panel.
- Release manifests bind version/build to the release tag and reject Boolean build
  numbers. Tests reproduced mismatched archive acceptance before the fix.
- Exact digital silence exits before model loading, refinement, delivery and saving.
- Synchronous speech decoders stop between chunks after cancellation. Previously
  they discarded the result but kept decoding later chunks before unloading.
  In the measured warm runs, cleanup fell from 9.23 to 3.50 seconds for Qwen 1.7B
  and from 17.34 to 6.76 seconds for FireRed. The current native decode call still
  finishes before unloading; cancellation does not interrupt that call.
- Whisper decodes sequential windows of at most 25 seconds, retaining later speech
  and propagating failure/cancellation instead of returning an incomplete prefix.
  Disabling its one-second tail clipping restores sub-second utterances; the
  0.717-second Hello fixture now passes, as it does for the other seven engines.
- Sidebar word totals refresh after single/all history deletion and explicit save
  retry, with stale asynchronous counts rejected.
- History uses a separate lightweight accessibility representation to avoid the
  native lazy-list scroll crash. Its real rows retain lazy rendering, selection,
  playback and shared presentation state. Visible rows expose their full spoken labels
  and shared actions; first/last, page and record navigation reveal further entries.
  A small positive visibility threshold excludes prefetched offscreen rows, keeping
  the timeline selection aligned with the first visible record.

Native History substring selection and Command-C passed in the final single-window
app. The earlier pointer failure was stale automation targeting of a second test
window. The replacement accessibility tree exposes full transcript labels and
Copy actions; native selected-range readback and a complete VoiceOver rotor session
are not certified by this run.

## Recognition observations

SenseVoice's English fixture contains spelling/number errors. Parakeet changes
"items" to "item". Qwen 1.7B changes some numbers in a repeated-sentence stress
fixture. Cohere compresses repetitions but transcribes the complete varied
37.04-second fixture, including its final marker. These outcomes remain visible
in the transcript evidence and are not counted as accurate recognition.

Whisper originally lost speech beyond 30 seconds; repaired 37.04- and 73.86-second
varied recordings include their final marker. Its repeated-sentence fixture still
compresses repetitions, and a distinct English/Chinese fixture omits the Chinese
portion with both automatic and Traditional Chinese script hints. Those are
remaining recognition-quality limitations, not successful accuracy checks.

## Boundaries

API-key providers, credential editors, credential migration and credential tests
are excluded by request. No release, push or replacement of the installed app is
part of this audit. Updater installation replaces only its temporary fixture.

This machine cannot certify unattached multi-input hardware, physical unplug/replug,
another Mac's privacy permission continuity, every supported spoken language,
public notarization or a real user's cross-application Accessibility insertion.
A later physical automation repeat returned no transcript while the MacBook
speakers were muted at zero volume. That repeat lacks a supplied speech signal;
the mute setting was preserved. The earlier successful physical automation remains
separate evidence, and the later run is not counted as a pass.

Physical modifier-hold/release, Spaces/multiple-display behavior and OS permission
grant/revoke flows need separate hardware/user-session acceptance. Existing native
fixtures cover their deterministic state logic where available.

One History crash caused the UI tool to relaunch the copied bundle without its
isolation arguments. It displayed existing preferences/history; testing stopped
immediately and only an update reminder was dismissed. No history, profile,
vocabulary or model edit occurred in that launch. The new `.e2e` startup guard was
then verified to exit with status 64 before constructing the normal app container.
